# Internetspuren löschen

- Quelle: https://www.am-anfang-war-es-liebe.de/internetspuren-loeschen/
- ID: 455, Eltern-ID: 0, geändert: 2018-04-23T08:18:40

---

Wenn Sie nicht wollen, das jemand anderes sieht, dass Sie auf dieser Internetseite waren, gibt es einen ganz einfachen Weg, seine Internetspuren zu löschen.

 

 

### Spuren beseitigen im Internet Explorer ab Version 11

 

moreDrücken Sie die Taste ALT, um die Menüleiste einzublenden.  
 Klicken Sie auf *Extras* und *Browserverlauf löschen..*. . Im nächsten Fenster können Sie alle verräterischen Spuren löschen. Sie können dazu die Vorauswahl übernehmen, oder sie fügen weitere Einträge hinzu, indem Sie einen Haken vor dem jeweiligen Eintrag setzen.  
 Zum Löschen klicken Sie auf *Löschen*.

 

 

### Spuren beseitigen in Firefox ab Version 27

 

Drücken Sie die Taste ALT, um die Menüleiste einzublenden.  
 Klicken Sie auf *Chronik*und *Neueste Chronik löschen..*. . Im nächsten Fenster können Sie alle verräterischen Spuren löschen. Wählen Sie dazu im Reiter oben*Alles.*Sie können jetzt die Vorauswahl übernehmen, oder sie fügen weitere Einträge hinzu, indem Sie einen Haken vor dem jeweiligen Eintrag setzen.  
 Zum Löschen klicken Sie auf Jetzt *Löschen*.
