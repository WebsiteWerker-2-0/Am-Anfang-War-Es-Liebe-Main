# Altseite am-anfang-war-es-liebe.de

Vollständige Sicherung der bisherigen WordPress-Website (WordPress 6.9.9), gezogen am 27.09.2026. Dient als Ausgangsmaterial für die neue Website in `../website/`, wird nicht ausgeliefert.

| Ordner | Inhalt |
|---|---|
| `json/` | Rohdaten der WordPress-REST-API: Seiten, Beiträge, Medien, Kategorien, Schlagwörter |
| `html/` | Gerenderte Seiten und Beiträge, wie sie online standen |
| `uploads/` | Alle Medien aus `wp-content/uploads` (Bilder, PDFs, Videos), Pfade wie im Original |
| `inhalte/` | Texte als Markdown aufbereitet, Einstieg: [`inhalte/README.md`](inhalte/README.md) |
| `inhalte/broschuere-2016.txt` | Text der Broschüre „Am Anfang war es Liebe …“ (Stand 1.8.2016) |

Inhalte aus der Altseite und der Broschüre von 2016 sind nicht geprüft (Nummern, Zeiten, Adressen, Namen). Vor Übernahme in die neue Website vom AG freigeben lassen (DESIGN-UND-ENTWICKLUNG.md, Abschnitt 13, Punkt 6).
