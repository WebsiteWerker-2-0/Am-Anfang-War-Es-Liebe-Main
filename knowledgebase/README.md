# Knowledgebase

Gemeinsame Wissensbasis für unsere Website. Alles in Markdown, damit wir beide (und Claude Code) direkt darauf zugreifen können.

## Bereiche

| Bereich | Inhalt |
|---|---|
| [design/](design/README.md) | Festgelegte Design-Entscheidungen: Farben, Typografie, Layout, Komponenten |
| [lieferungen-ag.md](lieferungen-ag.md) | Was der Arbeitskreis noch liefern oder freigeben muss, als Checkliste |

## Regeln

- Eine Datei pro Thema, kurz und aktuell halten.
- Festgelegtes steht in der jeweiligen Themendatei; *warum* und *wann* steht im [Entscheidungslog](design/entscheidungen.md).
- Offene Punkte als `- [ ]` markieren, bis sie entschieden sind.
