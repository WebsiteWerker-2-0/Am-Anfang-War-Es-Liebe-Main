# Handbuch für die Redaktion

So pflegen Sie Aktuelles, Termine und Kurse selbst. Sie brauchen dafür nur einen Browser und Ihr Konto. Änderungen erscheinen **sofort** auf der Website.

**Anmelden:** Adresse der Website, dahinter `/backend`, zum Beispiel `https://am-anfang-war-es-liebe.de/backend`. Der Bereich ist nirgends verlinkt. Geben Sie die Adresse nur an Kolleginnen weiter, die mitarbeiten.

Nach dem Passwort schickt die Website einen **sechsstelligen Code an Ihre E-Mail-Adresse**. Geben Sie ihn ein und klicken Sie **Bestätigen**. Der Code gilt 10 Minuten. Keine E-Mail? Im Spam-Ordner nachsehen oder **Neuen Code senden**.

Danach sehen Sie die **Startseite** mit großen Schaltflächen für die häufigsten Aufgaben. Das Menü öffnen Sie über das Symbol oben links. Es hat nur fünf Punkte:

| Menüpunkt | Wofür |
|---|---|
| **Aktuelles** | Meldungen für die Website schreiben |
| **Termine** | Termine mit Anmeldung anlegen, Anmeldungen ansehen |
| **Kurse** | Beschreibungen der Kurse (Krav Maga, Wendo) bearbeiten |
| **Mitglieder** | Liste „Wer im Arbeitskreis mitarbeitet“ auf der Seite Arbeitskreis |
| **Dateiarchiv** | Übersicht aller hochgeladenen Bilder und Dokumente |

Texte der festen Seiten (Hilfe, Selbstcheck, Kontakt …), Anlaufstellen, Menü und Fußbereich lassen sich hier bewusst **nicht** ändern. Dafür wenden Sie sich an Website Werker.

## Eine Meldung schreiben (Aktuelles)

1. Auf der Startseite **Neuen Beitrag schreiben** wählen.
2. **Titel**, **Datum** und **Verfasst von** eintragen (vorbelegt mit Ihrem Namen, erscheint auf der Website neben dem Datum), bei **Kurzfassung** zwei Sätze für die Liste.
3. Ein **Titelbild** wählen oder hochladen. Geben Sie die Bildbeschreibung an, sie hilft Screenreadern. Fotos im iPhone-Format HEIC nimmt das Backend nicht an, speichern Sie sie vorher als JPG.
4. Den **Text** schreiben. Mit den Knöpfen oben im Textfeld gibt es Zwischenüberschriften, Listen, fett und Links.
5. Rechts steht der **Status** schon auf **Veröffentlicht**. Soll der Beitrag noch nicht erscheinen, wählen Sie **Entwurf** (nur Sie sehen es). **Archiviert** heißt: bleibt erhalten, ist aber nicht mehr zu sehen.
6. **Speichern** (der dunkle Knopf oben rechts, er bleibt beim Scrollen sichtbar). Der Beitrag steht danach **ganz oben** in Aktuelles.
7. **Vorschau:** Das **Auge-Symbol** neben „Speichern“ zeigt rechts, wie der Beitrag auf der Website aussieht, auch bei Entwürfen. Nach jedem Speichern aktualisiert sie sich.

**Datei oder Bild mitten im Text:** Im Text an die gewünschte Stelle klicken, in der Leiste über dem Text ganz links auf das erste Symbol klicken und **Datei oder Bild** wählen. Dann eine Datei aus dem Archiv wählen oder neu hochladen, optional eine Beschriftung eintragen. Bilder erscheinen als Bild, PDFs und andere Dateien als Download-Link genau an dieser Stelle. Bei Bildern wählen Sie die **Position**: **Mittig** (volle Breite), **Links** oder **Rechts** (halbe Breite, Text und Listen stehen daneben). Zwei Bilder „Links“ direkt hintereinander stehen nebeneinander. Die Größe legt die Website fest, egal wie groß die Datei ist; links und rechts wird das Bild auf das Format 3:2 zugeschnitten.

**Text gestalten:** fett, kursiv, unterstrichen, durchgestrichen, Zwischenüberschriften in drei Größen (Überschrift 2 für Abschnitte, 3 und 4 für Unterabschnitte), Listen, Links. Überschrift 1 gibt es nicht, das ist der Titel. Schriftart, Größe und Farbe legt die Website fest, damit alles einheitlich aussieht.

**Reihenfolge ändern:** In der Liste „Aktuelles“ die Zeilen am Griff links ziehen.

**Downloads unter dem Beitrag:** Haken bei **Download-Bereich mit Dokumenten anzeigen** setzen. Dann je Dokument einen Namen und eine **PDF-Datei** wählen, auf Wunsch ein kleines Vorschaubild (sonst erscheint ein PDF-Symbol). Auf der Website steht unten eine Liste „Downloads“ mit Knopf zum Herunterladen. Andere Dateitypen als PDF sind hier nicht möglich.

**Archiv:** Steht ein Beitrag auf **Archiv**, verschwindet er aus der Liste und steht eingeklappt im **Archiv** ganz unten auf der Seite Aktuelles. Er bleibt aufrufbar.

## Einen Termin anlegen

1. Auf der Startseite **Neuen Termin anlegen** wählen.
2. **Name**, **Wann beginnt es?** und **Wo findet es statt?** eintragen, bei **Worum geht es?** einen kurzen Text.
3. Soll die Zahl der Teilnehmenden begrenzt sein, setzen Sie das Häkchen bei **Teilnehmerzahl begrenzen**. Ohne Häkchen gibt es keine Grenze, und weder das Backend noch die Website zeigen Plätze an. Mit Häkchen tragen Sie bei **Wie viele Plätze gibt es?** die Teilnehmerzahl ein. **Schon angemeldet** zählt die Anmeldungen über die Website selbst. Wer sich per Telefon oder E-Mail anmeldet, zählen Sie dazu, indem Sie die Zahl erhöhen. Die Website zeigt dann entsprechend weniger freie Plätze.
4. **Warteliste anbieten** (nur mit begrenzter Teilnehmerzahl) schalten Sie ein, wenn sich auch bei vollen Plätzen Interessentinnen eintragen dürfen.
5. Bei **Ausführlicher Text** (optional) Ablauf oder Hinweise schreiben, auch mit Datei oder Bild an einer Stelle im Text (wie bei Aktuelles).
6. **Speichern**. Der Status steht schon auf **Veröffentlicht**. Der Termin erscheint auf der Seite „Termine“ mit einem Anmeldeformular, bei begrenzter Teilnehmerzahl auch mit den freien Plätzen. Die Anzeige aktualisiert sich von selbst, wenn sich jemand anmeldet.

Unter **Weitere Angaben (optional)** stehen Ende, Zielgruppe, Kosten, Leitung und abweichende E-Mail-Adressen für die Anmeldungen. Mehrere Adressen trennen Sie mit Komma, zum Beispiel `kurse@beispiel.de, leitung@beispiel.de`.

**Absagen oder beenden:** Status auf **Archiviert** stellen oder den Termin **löschen**. Beim Löschen fragt das Backend „Sind Sie sicher?“; die Anmeldungen des Termins werden mitgelöscht.

## Kurse bearbeiten

Unter **Kurse** stehen die Beschreibungen von Krav Maga und Kids Krav Maga sowie Wendo für die Seite „Kurse“. Ein Kurs funktioniert wie ein Beitrag in Aktuelles: Die **Kurzfassung** erscheint in der Übersicht auf „Kurse“, der **Text** auf der eigenen Seite des Kurses, das **Titelbild** (freiwillig) über dem Text. Die Reihenfolge ändern Sie per Ziehen in der Liste. Termine mit Datum und Anmeldung zu einem Kurs legen Sie unter **Termine** an. Einen Kurs nicht mehr zeigen: Status **Archiviert** (nicht löschen).

## Mitglieder bearbeiten

Unter **Mitglieder** steht die Liste „Wer im Arbeitskreis mitarbeitet“. Je Eintrag: **Einrichtung**, optional **Bereich oder Funktion** und **Internetseite** (mit https://, dann ist der Name auf der Website verlinkt). Neue Einträge mit **Neu erstellen**, Reihenfolge per Ziehen in der Liste, nicht mehr dabei: Eintrag löschen. Namen von Personen nur mit deren Einverständnis.

## Anmeldungen ansehen und verwalten

Jede Anmeldung kommt als E-Mail an die eingestellte Adresse **und** steht unten im Termin unter **Anmeldungen** (Name, E-Mail, Status). Alle neuen Anmeldungen sehen Sie auch über die Startseite.

- **Absage:** die Anmeldung öffnen und den Status auf **Storniert** stellen oder die Anmeldung löschen. Name, E-Mail und Telefon lassen sich dort auch korrigieren.
- **Platz wieder freigeben:** die Anmeldung öffnen und den Status auf **Storniert** stellen. Der Platz ist sofort wieder frei.
- **Warteliste:** Wird ein Platz frei, öffnen Sie die Anmeldung der Wartenden, stellen sie auf **Angemeldet** und schreiben der Person.
- **Mit einer Teilnehmerin schreiben:** Antworten Sie einfach auf die E-Mail der Anmeldung.
- **Datenschutz:** Die Angaben sind persönliche Daten. Bitte nur für den Termin verwenden und **danach löschen** (Anmeldung öffnen, Löschen).

## Bilder und Dateien

Laden Sie Bilder und PDFs direkt dort hoch, wo Sie sie brauchen: im Beitrag, im Termin oder im Kurs. Das **Dateiarchiv** zeigt alles, was hochgeladen wurde. Dateien, die niemand mehr sehen soll, stellen Sie dort auf **nicht öffentlich**.

## Etwas rückgängig machen

Oben in jedem Beitrag, Termin und Kurs gibt es den Reiter **Versionen**. Dort wählen Sie einen früheren Stand und stellen ihn wieder her.

## Nur für Admins: Verwaltung

Admins sehen im Menü und auf der Startseite unter den Schaltflächen der Redaktion zusätzlich den Bereich **Verwaltung**.

**E-Mail und Anmeldungen einrichten:**

1. Bei **Anmeldungen gehen an diese E-Mail-Adresse** die Adresse eintragen, die die Anmeldungen bekommen soll.
2. Unter **Postfach für den Versand** die Angaben eines E-Mail-Postfachs eintragen. Das Passwort wird verschlüsselt gespeichert und danach nie wieder angezeigt, auch nicht für andere Admins. Feld leer lassen heißt: Das gespeicherte Passwort bleibt. Bei Hostinger finden Sie sie in hPanel beim Postfach: Server (meist `smtp.hostinger.com`), Port `465`, „Verschlüsselt“ an, Benutzername und Passwort des Postfachs.
3. **Speichern** und dann **Test-E-Mail senden**. Kommt die E-Mail im Postfach an, ist alles richtig. Sonst zeigt die Meldung den Grund.
4. Dasselbe Postfach verschickt auch die Nachrichten aus dem **Kontaktformular**. Sie gehen je nach Anliegen an die Frauenberatungsstelle oder die Gleichstellungsstelle und werden nirgends gespeichert. Zum Ausprobieren tragen Sie bei **Kontaktanfragen umleiten an** Ihre eigene Adresse ein; danach das Feld wieder leeren. Für ein anderes Postfach ändern Sie nur die Angaben unter **Postfach für den Versand**.

**Konten:** Unter **Redakteur:innen** legen Sie Konten an. Tragen Sie ein beliebiges Passwort ein. Die neue Person bekommt automatisch eine E-Mail mit einem Link **Passwort festlegen** (7 Tage gültig) und legt ihr eigenes Passwort fest. Mit **Zugangs-E-Mail senden** im Konto schicken Sie einen neuen Link. Die Rolle **Redaktion** darf Aktuelles, Termine, Kurse und Dateien pflegen, **Admin** zusätzlich Konten und E-Mail-Einstellungen verwalten. Ein Konto sperrt sich nach fünf falschen Passwörtern für zehn Minuten. Wer ihr Passwort vergessen hat, bekommt von einer Admin ein neues.

## Wenn etwas nicht klappt

- **Anmeldung kommt nicht per E-Mail an:** In der Anmeldung steht „E-Mail an den Arbeitskreis: Nicht gesendet“. Eine Admin prüft dann „E-Mail und Anmeldungen“ und sendet die Test-E-Mail. Die Anmeldung selbst ist trotzdem gespeichert.
- **Änderung erscheint nicht:** Seite neu laden. Bei Bildern kann der Browser das alte merken (Strg/Cmd + Umschalt + R).
